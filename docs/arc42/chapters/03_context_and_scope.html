Kontextabgrenzung: Die Apps kennen nur den Browser, alles andere hängt an Links und am Build

Das System „Lern-Apps“ ist das Monorepo mit allem, was daraus entsteht: die ausgelieferte Site unter https://lernapps.github.io/ (Apps, Mathe-Karte, Übersicht, diese Doku) und der Build, der sie erzeugt. Zur Laufzeit gibt es keinen Server und keine Schnittstelle, die das System selbst aufruft. Nachbarn erreicht es auf drei Wegen: über Links, denen ein Mensch oder ein LLM folgt (claude.ai, GitHub Issues, serlo.org); über das YouTube-iframe, das erst nach einem Klick entsteht; und zur Build-Zeit über Paketquellen und GitHub. Dieselbe Systemgrenze zeigt Kapitel 5, Ebene 1.

Technischer Kontext: HTTPS-GET, ein Deep Link, ein iframe und zwei Paketquellen

Kanal Protokoll / Format Einzelheiten

Browser → GitHub Pages

HTTPS GET

HTML, CSS, ES-Module (/kern/js/.js, /<app>/js/*), SVG/PNG, manifest.webmanifest, karte/data.json. Keine Cookies, kein POST.

Seite → claude.ai

Link https://claude.ai/new?q=<Prompt>;

Prompt „Lade <App-Adresse>tutor.md …“; erzeugt von TalkItOver, statischer <a>-Fallback in src/start.njk:48. Öffnet ein neues Fenster.

claude.ai → GitHub Pages

HTTPS GET durch das Web-Fetch-Werkzeug von Claude

<app>/tutor.md, <app>/llms.txt, /llms.txt, /karte/llms.txt. Ob Claude die Datei laden kann, entscheidet claude.ai.

Tutor → Kind → App

Aufgaben-URL

<app>/<seite>.html?<parameter>&seed=<n>, <app>/test.html?nr=<n>&modus=voll|schnell, Anker #warum … #uebung. Vertrag im llms.txt jeder App.

Kind → Tutor

Text (Zwischenablage)

Ergebniszeile Test Nr. 4711 (<App>, Schnelltest): 1 ✓ 2 ~ 3 ✗; „Aufgabe Nr. 42“; kopierter Aufgabenlink.

Seite → GitHub Issues

Link https://github.com/lernapps/lernapps.github.io/issues

Statischer <a> auf jeder Seite (entschieden am 23.09.2026, noch nicht umgesetzt). Keine Anfrage vor dem Klick; danach gelten die Regeln von GitHub.

Seite → serlo.org

Link https://de.serlo.org/<fach>/<id>/<titel>;

Statischer <a rel="noopener"> unter #serlo, nur wenn das Front Matter serlo: { url, titel } setzt (src/_includes/kompetenz.njk). Kein iframe, kein Vorschaubild, keine Anfrage vor dem Klick; pruefeSerloLinks (lib/pruefungen.js) bricht den Build bei anderen Adressen ab.

Seite → YouTube

<iframe src="https://www.youtube-nocookie.com/embed/<id>?autoplay=1">

Entsteht erst nach Klick oder bei gesetztem Merker (src/kern/js/video.js:12-15).
